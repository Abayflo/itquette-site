ITquette Autonomous Solutions - Starter Website

Files:
- index.html
- insights.html
- contact.html
- styles.css
- assets/logo.png (optional)

Run locally:
- Open index.html in your browser
- Or run: python -m http.server

Deploy:
- Netlify: drag and drop the folder
- GitHub Pages: push and enable Pages
- Vercel: static site

Customize:
- Replace hello@itquette.com with your email
- Replace the placeholder form with a form service
